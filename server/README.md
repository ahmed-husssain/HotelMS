# LuxuryStay Server

Backend REST API, real-time WebSocket hub, and billing engine for **LuxuryStay Hotel Management System**.

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure environment:**
   ```bash
   copy .env.example .env
   ```

3. **Seed database:**
   ```bash
   npm run seed
   ```

4. **Start development server:**
   ```bash
   npm run dev
   ```
